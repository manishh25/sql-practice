# SQL Subquery Practice

PostgreSQL-compatible SQL practice log with:
- Table setup and sample data
- Main subquery round (10 questions)
- Reinforcement round (5 questions)
- Original attempts preserved, including incomplete/incorrect attempts
- Corrected/accepted queries clearly labelled

## How to use
1. Open a PostgreSQL environment (for example, DB Fiddle).
2. Paste `subquery-practice.sql`.
3. Run the setup and then run query sections individually if you want to inspect each result set.

This is a learning log, not just a set of polished solutions: original attempts are retained so a reviewer can see the problem-solving process.
