# SQL CTE Reinforcement (Questions 1–5)

**Dialect:** PostgreSQL

This pack preserves the five reinforcement questions, sample data, original attempts, explanations of corrections, and accepted/corrected solutions.

## Files
- `cte-reinforcement.sql` — tables, sample data, questions, attempts, corrected queries, and notes.

## Topics covered
1. Multiple CTEs, `LEFT JOIN`, and `COALESCE`
2. Comparing department average and overall average using multiple CTEs and `CROSS JOIN`
3. Filtering rows before aggregation
4. `UNION ALL` with a CTE
5. CTE combined with `DENSE_RANK()`

## How to use
Run the SQL file in PostgreSQL. The setup section recreates the sample tables. Each question section contains the original attempt or approach, the reason for correction where applicable, and the accepted solution.
