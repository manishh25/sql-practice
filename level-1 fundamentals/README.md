# SQL Practice — Levels 1 and 2

This repository contains 20 practice exercises based on the queries solved in the practice session.

- `level-1/`: fundamentals and filtering (10 questions)
- `level-2/`: aggregation, `GROUP BY`, and `HAVING` (10 questions)

Each SQL file contains the question, table setup, sample rows, your submitted attempt, and the final accepted query. Level 2 Question 4 also preserves the initial incorrect attempt and explains what needed correction.

## Run the files

The examples use PostgreSQL-compatible SQL. Open a file in a PostgreSQL client or go to https://dbfiddle.uk/ and select PostgreSQL. Paste and run the file.

Each file creates a table and inserts sample data. To rerun it, use a fresh schema/database or drop the table created by that file first.

GitHub stores the SQL files; it does not execute SQL by itself.
